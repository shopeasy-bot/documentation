# Configurações Gerais

Acesse e personalize todas as configurações do seu bot em um único lugar.

## Acessando Configurações

Para acessar o menu de configurações gerais, use o comando:

<DiscordSlashCommand
  name="configuracoes"
  description="[⚙️] Acesse as configurações gerais"
/>

<Steps>
<Step>
## Menu de Configurações

Após executar o comando, será exibido o menu principal de configurações.

![Menu de configurações gerais](/images/configs/menu-configuracoes.png)

</Step>

<Step>
## Selecione a Categoria

Clique no **select menu** e escolha a categoria de configuração que deseja acessar.

As opções disponíveis são:
- **Configurações de Compra** - Configure o sistema de pagamentos e compras
- **Configurações de Canais e Categorias** - Defina onde as mensagens serão enviadas
- **Configurações de Permissões** - Gerencie quem pode usar cada funcionalidade
- **Configurações de Personalização** - Customize a aparência e identidade do bot

</Step>
</Steps>

## Navegando Entre Configurações

Você pode navegar livremente entre as diferentes categorias de configuração:

1. Abra o menu com `/configuracoes`
2. Selecione uma categoria
3. Faça as alterações desejadas
4. Volte ao menu principal para acessar outra categoria
5. Ou feche o menu quando terminar

<Callout type="success">
Todas as alterações são salvas automaticamente ao confirmar cada configuração.
</Callout>

## Dicas de Configuração

**Recomendações importantes:**

- **Configure primeiro os canais:** Defina onde tudo será enviado antes de ativar funcionalidades
- **Teste as permissões:** Sempre teste se os cargos estão funcionando corretamente
- **Personalize com identidade:** Use cores e logos que representem sua marca
- **Revise regularmente:** Verifique se as configurações ainda atendem suas necessidades

<Callout type="warn">
Algumas configurações são essenciais para o funcionamento do bot. Certifique-se de configurar ao menos os canais básicos antes de começar a usar.
</Callout>
