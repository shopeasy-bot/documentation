## Canais Disponíveis

### <Bell className="inline w-5 h-5" /> Notificações Públicas

Canal onde serão enviadas notificações de vendas **sem dados confidenciais**.

**O que é enviado neste canal:**
- Notificação de nova compra (sem dados sensíveis)
- Nome do produto vendido
- Horário da venda
- Valor da compra (opcional)

**Como configurar:**
- Clique no **select menu** abaixo de "Notificações Públicas"
- Selecione um canal existente, OU
- Clique em **"Criar Canal"** para criar um novo automaticamente

<Callout type="info">
Este canal pode ser visualizado por membros do servidor para mostrar atividade da loja.
</Callout>

**Exemplo de configuração:**
```
Canal recomendado: #vendas ou #notificações
Permissões: Apenas visualizar
```

---

### <Lock className="inline w-5 h-5" /> Notificações Privadas

Canal onde serão enviadas notificações de vendas **com dados confidenciais**.

**O que é enviado neste canal:**
- Detalhes completos da compra
- Dados do comprador
- Informações de pagamento
- Produto entregue
- Status da transação

**Como configurar:**
- Clique no **select menu** abaixo de "Notificações Privadas"
- Selecione um canal existente, OU
- Clique em **"Criar Canal"** para criar um novo automaticamente

<Callout type="warn">
**Importante:** Este canal deve ser privado e acessível apenas pela equipe administrativa!
</Callout>

**Exemplo de configuração:**
```
Canal recomendado: #logs-vendas ou #admin-vendas
Permissões: Apenas administradores
```

---

### <Star className="inline w-5 h-5" /> Avaliações

Canal onde serão enviadas as avaliações feitas pelos clientes após a compra.

**O que é enviado neste canal:**
- Avaliação do cliente (estrelas)
- Comentário do cliente
- Produto avaliado
- Data da avaliação

**Como configurar:**
- Clique no **select menu** abaixo de "Avaliações"
- Selecione um canal existente, OU
- Clique em **"Criar Canal"** para criar um novo automaticamente

<Callout type="success">
Exibir avaliações publicamente aumenta a credibilidade da sua loja!
</Callout>

**Exemplo de configuração:**
```
Canal recomendado: #avaliações ou #feedback
Permissões: Apenas visualizar
```

---

### <ShoppingBag className="inline w-5 h-5" /> Categoria Carrinhos

Categoria onde serão criados os canais de carrinho (tickets de compra) dos clientes.

**O que acontece nesta categoria:**
- Criação automática de canais privados para cada compra
- Cliente discute detalhes da compra
- Suporte tira dúvidas
- Entrega do produto

**Como configurar:**
- Clique no **select menu** abaixo de "Categoria Carrinhos"
- **Selecione uma categoria existente** no servidor

<Callout type="info">
<Plus className="inline w-4 h-4" /> Diferente dos canais, a categoria **não pode ser criada automaticamente** - você deve selecionar uma existente.
</Callout>

**Exemplo de configuração:**
```
Categoria recomendada: 🛒 CARRINHOS ou 🎫 ATENDIMENTO
Permissões: Sincronizadas da categoria
```

<Callout type="warn">
Certifique-se de que a categoria escolhida tem as permissões corretas:
- @everyone: Sem acesso
- Bot: Gerenciar canais, enviar mensagens
- Equipe: Ver canais
</Callout>

## Sistema de Draft

<Callout type="warn" icon={<Clock />}>
**Importante:** As alterações ficam salvas como rascunho por **24 horas**.

Se você não clicar em "Salvar Alterações" dentro deste período, todas as modificações serão perdidas!
</Callout>

### Como Funciona

1. Configure os canais desejados
2. As mudanças ficam temporariamente salvas (draft)
3. Você tem até 24 horas para revisar e fazer mais alterações
4. Clique em **"Salvar Alterações"** para aplicar definitivamente

**Exemplo de uso:**
```
10:00 - Você configura o canal de notificações públicas
10:15 - Você configura o canal de avaliações
10:30 - Você seleciona a categoria de carrinhos
10:45 - Você clica em "Salvar Alterações"
✅ Todas as configurações são aplicadas de uma vez
```

### <Save className="inline w-5 h-5" /> Salvando as Alterações

Após configurar todos os canais desejados, **não se esqueça** de clicar no botão **"Salvar Alterações"**.

O que acontece ao salvar:
- ✅ Os canais são vinculados ao sistema
- ✅ O bot começa a enviar notificações nos canais configurados
- ✅ Carrinhos serão criados na categoria selecionada
- ✅ O draft é limpo

<Callout type="success">
Configurações salvas com sucesso! Os canais foram vinculados ao sistema.
</Callout>

<Callout type="warn" icon={<AlertCircle />}>
**Atenção:** Se você fechar o menu sem salvar, as alterações permanecem no draft por 24 horas. Você pode voltar e continuar editando.
</Callout>

## Criando vs Selecionando Canais

### <Plus className="inline w-5 h-5" /> Criar Canal

Quando você clica em **"Criar Canal"**, o bot:
- Cria automaticamente um novo canal
- Aplica o nome sugerido (ex: `vendas-publicas`)
- Configura permissões básicas
- Vincula o canal ao sistema

**Vantagem:** Rápido e automático

---

### Selecionar Canal Existente

Quando você seleciona um canal existente:
- Você escolhe entre os canais do servidor
- Mantém o nome e permissões atuais
- Apenas vincula ao sistema do bot

**Vantagem:** Mais controle sobre nome e permissões

<Callout type="info">
Você pode alterar os canais configurados a qualquer momento repetindo o processo.
</Callout>

## Estrutura Recomendada

Organize seu servidor com esta estrutura sugerida:

```
📢 PÚBLICOS
├─ #vendas          (Notificações Públicas)
└─ #avaliações      (Avaliações)

🔒 ADMINISTRAÇÃO
├─ #logs-vendas     (Notificações Privadas)
└─ #logs-sistema

🛒 CARRINHOS        (Categoria Carrinhos)
├─ 🛒・carrinho-001
├─ 🛒・carrinho-002
└─ ...
```

## Dicas de Configuração

**Boas práticas:**

- **Separe público e privado:** Nunca misture dados sensíveis em canais públicos
- **Nomes claros:** Use nomes descritivos para os canais
- **Permissões corretas:** Revise as permissões de cada canal
- **Categoria organizada:** Mantenha a categoria de carrinhos limpa e organizada
- **Teste tudo:** Faça uma compra teste para verificar se as notificações estão funcionando

**Exemplos de bons nomes:**
```
✅ #vendas-publicas
✅ #logs-admin
✅ #feedback-clientes
✅ 🛒 CARRINHOS
```

**Exemplos de nomes ruins:**
```
❌ #canal1
❌ #logs
❌ #teste
❌ categoria sem nome
```

## Solução de Problemas

### Notificações não estão chegando

1. Verifique se você salvou as alterações
2. Confirme se o bot tem permissão para enviar mensagens no canal
3. Certifique-se de que o canal ainda existe

### Carrinhos não estão sendo criados

1. Verifique se a categoria foi selecionada e salva
2. Confirme se o bot tem permissão de "Gerenciar Canais" na categoria
3. Verifique se a categoria não atingiu o limite de 50 canais

### Draft expirou

1. Refaça as configurações
2. Lembre-se de salvar dentro de 24 horas
3. Configure tudo de uma vez para evitar esquecimento
