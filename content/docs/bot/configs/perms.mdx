# Permissões

As permissões definem quais cargos da equipe podem usar cada área do ShopEasy.

## Como o acesso é decidido

1. **Nenhum cargo configurado ainda:** somente membros com **Administrador** no Discord têm acesso aos comandos de gerenciamento.
2. **Pelo menos um cargo configurado:**
   - O **dono do servidor** sempre tem acesso total.
   - Os demais membros têm acesso conforme as permissões dos **cargos** que possuem. As permissões de vários cargos se somam.
   - A permissão **Administrador** (do ShopEasy) libera tudo.

<Callout type="warn" icon={<AlertCircle />}>
  **Atenção:** depois que o primeiro cargo é configurado, ter **Administrador no Discord não basta mais**. Antes de salvar, inclua o seu cargo (ou o cargo dos administradores) com a permissão **Administrador**.
</Callout>

## Requisitos

- Apenas o **dono do servidor** pode abrir o menu de Permissões.
- É necessário um **plano pago** (a partir do Essencial).

## Configurando

<Steps>
<Step>
### Abra o menu
Use `/configuracoes` e selecione **🔐 Permissões**.

![Menu de configuração de permissões](/images/configs/menu-permissoes.png)
</Step>

<Step>
### Selecione um cargo

![Seleção de cargo](/images/configs/selecao-cargo.png)
</Step>

<Step>
### Marque as permissões
Escolha as permissões do cargo no seletor.
</Step>

<Step>
### Salve
Clique em **Salvar Alterações**. O rascunho dura até 24 horas.
</Step>
</Steps>

## Permissões Disponíveis

| Permissão | Chave | Libera |
| --- | --- | --- |
| 📦 **Produtos** | `manage_products` | `/produto`, `/catalogo`, `/cupom`, `/galeria` |
| 🛒 **Carrinhos** | `manage_carts` | Agir em carrinhos de outros usuários, aprovar pagamentos no carrinho, restaurar carrinhos, botões de log de vendas e reembolsos |
| ⚙️ **Configurações** | `manage_config` | `/configuracoes`, `/personalizar`, `/integracoes`, `/plano`, `/ticket` |
| 📊 **Vendas** | `view_orders` | `/vendas perfil`, `/vendas relatorio`, `/vendas resumo`, `/rank` |
| 💳 **Processar Pagamentos** | `process_payments` | Disponível no menu, mas nenhum comando exige esta permissão atualmente |
| 🏦 **Gerenciar Pagamentos** | `manager_payments` | `/pagamento configurar`, `/pagamento aprovar`, `/pagamento consultar` |
| 🛡️ **Gerenciar Cargos** | `manage_roles` | Disponível no menu, mas nenhum comando exige esta permissão atualmente |
| 🤖 **Gerenciar Bot** | `manager_bot` | `/bot`, `/automacoes`, `/voz` |
| 👑 **Administrador** | `full_access` | Tudo, incluindo `/painel` e `/saldo dar` |

<Callout type="info">
  `/dm` e `/clientes vincular` exigem a permissão interna **Gerenciar clientes** (`manage_customers`), que não aparece no menu. Na prática, esses comandos ficam disponíveis para o dono do servidor e para cargos com **Administrador**. Antes de qualquer cargo ser configurado, ficam disponíveis para quem tem Administrador no Discord.
</Callout>

## Estrutura Recomendada de Cargos

| Cargo | Permissões sugeridas |
| --- | --- |
| Gerente | Administrador |
| Estoquista | Produtos |
| Atendente | Carrinhos, Vendas |
| Financeiro | Gerenciar Pagamentos, Vendas |

## Solução de Problemas

### Um administrador perdeu acesso depois de configurar
Depois que um cargo é configurado, o acesso passa a depender dos cargos. O dono do servidor deve dar ao cargo dos administradores a permissão **Administrador**.

### Um membro recebe "Você não possui permissão para utilizar esse comando!"
Confira se algum cargo do membro tem a permissão exigida pelo comando (veja a tabela acima) e se as alterações foram **salvas**.

### Não consigo abrir o menu de Permissões
Somente o **dono do servidor** pode abrir este menu, e é preciso ter um plano pago ativo.
