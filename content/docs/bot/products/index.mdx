# Cadastro de Produtos

**Permissão necessária:** Produtos (`manage_products`).

## Criando um Produto

<DiscordSlashCommand
  name="produto"
  subcommand="criar"
  description="[📦] - Cadastre um produto para venda"
  options={[
    { name: "referencia", type: "text" },
    { name: "canal", type: "text" }
  ]}
/>

| Opção | Obrigatória | Descrição |
| --- | :---: | --- |
| `referencia` | Sim | Identificador único do produto (SKU) |
| `canal` | Não | Canal de texto onde a mensagem será publicada. Se omitido, usa o canal atual |

<Steps>
<Step>
### Escolha a referência

A referência identifica o produto nos outros comandos.

- Deve ser **única** no servidor.
- Use apenas **letras, números e hífen** (`-`), sem espaços.
- Tamanho entre **3 e 20 caracteres**.

```
vip-30-dias
produto-001
key-minecraft
```
</Step>

<Step>
### Mensagem publicada

O bot publica a mensagem do produto. Enquanto ele não for configurado, aparece assim:

<DiscordProductCard
  title="Sem título configurado.."
  description="Sem descrição configurada..."
  price="R$ 10,00"
  stock="0 unidades disponíveis"
/>

O preço padrão de um produto sem valor definido é **R$ 10,00**.
</Step>

<Step>
### Configure

Use `/produto configurar` para definir título, descrição, preço e estoque. Veja [Configuração](/docs/products/configs).
</Step>
</Steps>

## Outros subcomandos de produto

| Subcomando | O que faz | Plano |
| --- | --- | --- |
| `/produto configurar [referencia]` | Abre o menu de configuração. Sem referência, mostra a lista de produtos | — |
| `/produto definir [referencia]` | Publica (de novo) a mensagem do produto no canal atual. Uma mesma referência pode ter várias mensagens, e todas são atualizadas ao salvar | — |
| `/produto esgotados` | Lista os produtos sem estoque | — |
| `/produto solicitar [canal]` | Envia o painel **Solicitar Produto**. As solicitações chegam ao canal de Notificações Privadas | Essencial |
| `/produto enviar usuario quantidade` | Entrega manualmente um produto de **estoque automático** a um usuário (quantidade mínima 1) | Essencial |

## Produto Não Apareceu?

<Callout type="warn" icon={<AlertCircle />}>
  O bot precisa **ver o canal** e **enviar mensagens** nele. Se a mensagem não foi publicada, confira as permissões do cargo do bot no canal e use `/produto definir` para publicar novamente.
</Callout>
