## Requisitos

- Permissão **Configurações** no ShopEasy **e** permissão **Administrador** no Discord.
- Conta no site do ShopEasy. Se você ainda não fez login, o bot mostra um botão para [shopeasy.site/login](https://shopeasy.site/login).

## Primeira assinatura

<Steps>

<Step>
### Abra o menu de planos

<DiscordSlashCommand
  name="plano"
  subcommand="adquirir"
  description="[✨] - Adquira um plano para o servidor."
/>

O bot mostra os planos **Essencial**, **Profissional** e **Completo** com preço e recursos. O plano atual aparece marcado como **Plano Atual**.
</Step>

<Step>
### Clique em "Adquirir" no plano desejado

Um formulário é aberto com três campos:

| Campo | Opções |
| --- | --- |
| **Duração** | Plano Mensal (30 dias), Trimensal (90 dias) ou Anual (365 dias) |
| **Forma de pagamento** | PIX ou Cartão de Crédito ou Débito |
| **Cupom** (opcional) | Código de desconto |

<Callout type="success">
  Na primeira assinatura, use o cupom **`PRIMEIRACOMPRA`** para ganhar **10% de desconto**.
</Callout>
</Step>

<Step>
### Pague

<Tabs items={['PIX', 'Cartão']}>
  <Tab value="PIX">
    1. O bot exibe o **QR Code** e o código **PIX Copia e Cola** (use o botão **Copiar Código PIX**).
    2. Abra o app do banco e pague.
    3. O plano é ativado assim que o pagamento é confirmado.
  </Tab>
  <Tab value="Cartão">
    1. Clique em **Ir para o Pagamento**.
    2. Preencha os dados do cartão na página segura.
    3. O plano é ativado assim que o pagamento é confirmado.
  </Tab>
</Tabs>

Os dados de pagamento também são enviados para sua **mensagem direta**, caso suas DMs estejam abertas.
</Step>

</Steps>

## Gerenciar ou renovar

<DiscordSlashCommand
  name="plano"
  subcommand="gerenciar"
  description="[✨] - Gerencie o plano ativo do servidor."
/>

Mostra o status, o titular, as datas de início e de vencimento e os dias restantes. Os botões disponíveis são:

- **Renovar Plano** (ou **Reativar Plano**, se vencido): abre o mesmo fluxo de pagamento.
- **Fazer Upgrade**: troca para um plano superior. Para o Enterprise, o botão leva ao [suporte](https://shopeasy.site/support).
- **Ver Planos**: abre esta documentação.
- **Resgatar Bot Exclusivo**: aparece no plano Completo enquanto o servidor ainda não tem um bot exclusivo. Veja [Bot exclusivo](/docs/bot-exclusivo).

## Resgatar um código

<DiscordSlashCommand
  name="plano"
  subcommand="resgatar"
  description="[✨] - Resgate um key de plano"
  options={[{ name: "codigo", type: "text" }]}
/>

Use para ativar códigos de plano, como a recompensa de 10 vendas.

## Problemas comuns

<Callout type="warn">
  **Pagamento confirmado, mas o plano não ativou?** Aguarde alguns minutos e confira com `/plano gerenciar`. Se o problema continuar, procure o [suporte](https://shopeasy.site/support) com o comprovante.
</Callout>

<Callout type="warn">
  **Não consigo usar o comando?** `/plano adquirir` exige a permissão **Administrador** do Discord, além da permissão **Configurações** do ShopEasy. Veja [Permissões](/docs/configs/perms).
</Callout>
