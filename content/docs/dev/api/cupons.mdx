## ✨ Criar Cupom

<div className="flex items-center gap-2 my-4 font-mono text-sm">
  <span className="bg-green-500/15 text-green-400 border border-green-500/30 px-2 py-0.5 rounded font-bold">POST</span>
  <code>/guilds/\{guildId\}/coupons</code>
</div>

### Body

<TypeTable
  type={{
    reference: { description: "Código do cupom (ex: `DESCONTO10`).", type: "string", required: true },
    createdBy: { description: "ID Discord do criador.", type: "string", required: true },
  }}
/>

<Callout type="info">
  Após criar o cupom, use o `PATCH` para definir desconto, limites e regras.
</Callout>

### Exemplo

```json
{
  "reference": "VERAO25",
  "createdBy": "123456789012345678"
}
```
