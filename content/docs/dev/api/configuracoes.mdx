### Provedores de Pagamento

<TypeTable
  type={{
    providers: {
      description: "Lista de provedores de pagamento ativos.",

    },
  }}
/>

**Valores disponíveis para `providers`:**

| Valor | Descrição |
|-------|-----------|
| `pixsemiauto` | PIX manual (copia e cola) |
| `mercadoPago` | PIX automático via Mercado Pago |
| `pagseguro` | PIX automático via PagSeguro |
| `asaas` | PIX automático via Asaas |
| `efibank` | PIX automático via EFI Pay |
| `wallet` | Carteira interna |
| `stripe` | Cartão de crédito/débito via Stripe |
| `nowpayments` | Criptomoedas via NowPayments |

<Callout type="warn">
  Alterar canais ou cargos com IDs incorretos pode quebrar o fluxo de vendas. Verifique os IDs antes de atualizar.
</Callout>
