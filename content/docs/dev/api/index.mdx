A API REST do ShopEasy permite integrar e automatizar todas as operações da sua loja diretamente pelo código.

## 🌐 Base URL

```
https://api.shopeasy.site
```

## 🔐 Autenticação

Todas as rotas exigem um **Bearer Token** no header `Authorization`.

```http
Authorization: Bearer SEU_TOKEN_AQUI
```

Crie sua chave de API nas configurações do bot com o comando `/keys`.

<Callout type="warn">
  Nunca exponha sua chave de API publicamente. Trate-a como uma senha.
</Callout>

## 🗂️ Estrutura das Rotas

A maioria dos endpoints é escopada por servidor Discord:

```
/guilds/{guildId}/products
/guilds/{guildId}/coupons
/guilds/{guildId}/configs
/guilds/{guildId}/catalogs
```
